# Night play

Закрытый кинозал для двоих: синхронный плеер, чат поверх видео, плейлист с разделами. Дизайн — «Rose Smoke» (сливово-чёрный фон, пыльно-розовый акцент, дымка), экран подтверждения 18+, интерфейс на русском.

**Стек:** Next.js 15 (статический экспорт для GitHub Pages), TypeScript, Tailwind, Framer Motion, Firebase Firestore (синхронизация и чат), Cloudflare R2 (видео).

## Запуск

```bash
npm install
npm run dev
```

## Новый чат и как он отделён от старого

Сайт пишет в **другие коллекции Firestore**, поэтому чат начинается пустым, а старый чат с Nicol не удаляется и не меняется:

| Что | Старый сайт | Night play |
|---|---|---|
| Комната (плейлист, плеер) | `watchRoom/room` | `nightPlayRoom/room` |
| Чат | `watchRoomChat` | `nightPlayChat` |
| «В сети» | `watchRoomPresence` | `nightPlayPresence` |

Имена задаются в `src/lib/room-config.ts` (или переменной `NEXT_PUBLIC_ROOM_NAMESPACE`).
Ключи localStorage тоже свои (`nightplay-…`), чтобы два сайта на одном домене `*.github.io` не мешали друг другу.

### Обязательно: правила Firestore

Новые коллекции нужно разрешить в правилах, иначе чат и плеер не заработают. В консоли Firebase → Firestore → Rules **добавьте** блоки из `firestore.rules.example` к существующим правилам (старые не удаляйте).

## Настройка

Скопируйте `.env.example` в `.env.local` и заполните (те же значения Firebase и R2, что и у старого сайта, если используете тот же проект).

Деплой на GitHub Pages — как раньше (`.github/workflows/deploy.yml`). Имя репозитория для `basePath` берётся автоматически, менять `next.config.ts` не нужно. Секреты — те же, что в `.env.example`.

## Фото

В `site-config.ts` у каждого человека есть поле `photo`. Положите файл в `public/images/` и укажите путь (например `"/images/k.jpg"`). Без фото показывается инициал.
